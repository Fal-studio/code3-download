من التحميل إلى أول دورية في أربع خطوات

لا تحتاج إلى معرفة مكان كل ملف. البرنامج يرتّب كل شيء ويتحقق من المتطلبات قبل التثبيت.

  1. حمّل البرنامجشغّل ملف Code3-Setup.exe وثبّته.
  2. سجّل الدخولبحساب Discord في مجتمع Code 3.
  3. حدّد مجلد اللعبةغالبًا يعثر عليه البرنامج وحده.
  4. اختر وثبّتاختر المودات بنفسك، أو استخدم التثبيت الذكي.

كل ما تحتاجه لتشغيل LSPDFR بدون صداع

أدوات صُممت للمشاكل التي يواجهها كل من حاول تركيب مودات الشرطة يدويًا.

التثبيت الذكي

اختر نوع التجربة، والبرنامج يثبّت مجموعة مودات متوافقة مع متطلباتها، ومعها gameconfig وLenny's Mod Loader تلقائيًا حتى لا تتوقف اللعبة أثناء التحميل.

أسئلة شائعة

هل البرنامج مجاني؟

نعم، Code 3 Installer مجاني بالكامل، وكل المودات الأساسية تُثبَّت بدون أي مقابل.

هل يعمل مع GTA V Enhanced؟

لا، البرنامج يدعم GTA V Legacy فقط، لأن LSPDFR وRagePluginHook يعملان عليها.

لماذا يطلب تسجيل الدخول بـ Discord؟

البرنامج مخصص لأعضاء مجتمع Code 3، ومن خلال السيرفر تصلك الأخبار والدعم والتحديثات.

هل يغيّر ملفات اللعبة الأصلية؟

يحتفظ بنسخة من كل ملف يستبدله، ويمكنك حذف أي مود أو إرجاع اللعبة لحالتها الأصلية من داخل البرنامج.

اللعبة تتوقف بعد التثبيت، ماذا أفعل؟

افتح فحص الكراش في البرنامج؛ فهو يقرأ السجلات ويخبرك بالسبب وطريقة الإصلاح، ومعظم المشاكل تُحل بضغطة.

لمن حقوق المودات؟

كل مود ملك لصانعه، وروابط صفحاته الأصلية موجودة داخل البرنامج. Code 3 Installer يسهّل التثبيت فقط.

جاهز لأول دورية؟ حمّل البرنامج الآن.
