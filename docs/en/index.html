Requirements

  • A genuine copy of GTA V Legacy (Enhanced is not supported)
  • Windows 10 or Windows 11
  • A Discord account in the Code 3 community
  • An internet connection while mods download

On the first launch

  • Windows may show a warning because the installer is not digitally signed yet.
  • If you downloaded it from this page, click More info then Run anyway.
  • Don't close the app while it downloads or installs.

Frequently asked questions

Is it free?

Yes. Code 3 is completely free, and every core mod installs at no cost.

Does it work with GTA V Enhanced?

No. It supports GTA V Legacy only, which is what LSPDFR and RagePluginHook run on.

Why does it ask me to sign in with Discord?

The app is made for members of the Code 3 community. News, support and updates reach you through the server.

Does it change my original game files?

It keeps a copy of every file it replaces, so you can remove any mod or restore the original game from inside the app.

My game crashes after installing. What now?

Open the crash check in the app. It reads the logs, tells you the cause and how to fix it, and most problems are fixed in one click.

Who owns the mods?

Every mod belongs to its author, and links to their original pages are inside the app. Code 3 only makes installing easier.
